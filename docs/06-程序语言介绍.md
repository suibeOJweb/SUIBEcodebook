# 程序语言介绍

> 返回 [目录](../README.md)

语言只是工具，但第一门主语言会塑造你的技术视野和求职方向。本章从常用到少见逐一介绍，重点是**每门语言实际用来干什么、值不值得学**。

## 第一梯队：最常见的四门

> 推荐选一门作为主要开发领域，学透，再触类旁通。

### Python

- **干什么**：AI/机器学习领域的绝对霸主（PyTorch、TensorFlow 都是它），同时也是全世界最常用的语言。数据分析、爬虫、自动化脚本、后端小服务都能做。
- **优点**：语法简单，上手最快，生态无敌；写 AI、写脚本、做实验都是首选。
- **缺点**：运行慢，工程化大型项目时类型约束弱；只会 Python 在纯开发岗竞争力不足。
- **建议**：几乎人人必学。走 AI 方向它是母语；走其他方向它也是最好的第二语言和日常工具。

### Java

- **干什么**：国内后端岗位最常见的语言，大厂业务系统的主流选择（Spring 全家桶）。
- **优点**：岗位数量大、生态成熟、工程化规范，面向就业非常稳。
- **缺点**：语法啰嗦，国内 Java 后端也是最"卷"的赛道之一。
- **建议**：目标国内后端就业就学它，配合 [JavaGuide](05-资源推荐.md) 路线走。

### JavaScript

- **干什么**：浏览器里唯一的语言，前端必备；配合 Node.js 也能写后端。
- **优点**：入门快，写完立刻能在浏览器里看到效果，正反馈强；前端岗位刚需。
- **缺点**：语言本身设计粗糙（历史包袱多），实际开发基本都转向 TypeScript 了。
- **建议**：想做前端/全栈就从它开始，但别停留在 JS，尽快过渡到 TS。

### C++

- **干什么**：六边形战士——游戏引擎、客户端、高频交易、AI infra（推理引擎、CUDA）、嵌入式、竞赛，各大领域都能用 C++ 做。
- **优点**：性能天花板，最接近机器，学完对计算机的理解远超别人；算法竞赛（ACM 等）指定语言。
- **缺点**：难，真难。语法复杂、坑多，学习曲线陡峭。
- **建议**：想走游戏、AI infra、高性能方向，或者打竞赛，选它。只想快速做项目就业的话别从它入门。

## 第二梯队：各有山头的语言

### TypeScript / Node.js

- 给 JS 加上了类型系统，现代前端的事实标准，Vue/React 项目现在基本都是 TS。
- Node.js 让 JS/TS 跑在服务端，全栈开发者一把梭：前后端同一门语言。
- **建议**：学前端必然会走到这里，不用单独"学"，JS 熟了自然过渡。

### Go

- **干什么**：云原生和后端基础设施——Docker、Kubernetes 都是 Go 写的；国内不少厂的后端也在用。
- **优点**：语法极简，并发模型舒服，编译快部署方便，后端岗位在增长。
- **缺点**：生态偏基础设施，业务后端岗位总量仍不如 Java。
- **建议**：作为后端方向的第二选择，或者 Java 学腻了的换口味选项。

### Rust

- **干什么**：系统级编程的新贵——操作系统组件、区块链、高性能服务，目标是替代 C/C++。
- **优点**：内存安全不靠垃圾回收，性能对标 C++，连续多年当选"最受喜爱语言"。
- **缺点**：学习曲线比 C++ 还陡（所有权机制劝退），岗位数量目前仍然少。
- **建议**：很有前途但岗位还没跟上，适合有兴趣折腾的同学，不建议作为唯一的就业赌注。

### C

- **干什么**：操作系统、嵌入式、驱动——一切贴着硬件的地方。
- **建议**：就算不专门用，也值得学个大概。C 是理解内存、指针和"程序到底怎么跑"的最短路径，学完再看别的语言都是降维打击。

## 第三梯队：特定平台的语言

### C#

- 微软系语言，两大主场：**Unity 游戏开发**和 Windows 企业应用（.NET）。
- 语言本身设计得很好，但国内岗位面窄。想进游戏行业做 Unity 就学，否则优先级不高。

### Kotlin

- JetBrains 出品，**Android 开发的官方语言**（已取代 Java），语法比 Java 现代得多。
- 想做安卓就学，不做移动端可以跳过。

### Swift

- 苹果生态语言，iOS/macOS 开发的唯一选择。
- 想做 iOS 开发就学，前提是你有一台 Mac。

## 怎么选（一句话版）

| 目标 | 首选语言 |
| --- | --- |
| AI / 数据 / 科研 | Python |
| 国内后端就业 | Java（备选 Go） |
| 前端 / 全栈 | JavaScript → TypeScript |
| 游戏 / 竞赛 / 高性能 | C++（Unity 则 C#） |
| 移动端 | Kotlin（Android）/ Swift（iOS） |

最后记住：**语言之间的迁移成本远低于你的想象**。把一门语言学深（包括它的生态和工程实践），第二门通常几周就能上手。纠结"学哪门"不如现在就开写。
