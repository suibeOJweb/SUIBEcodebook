### Agent

AI 的应用层方向，偏向于开发。

首先你去deepseek/kimi/qwen官方api网站申请一个api key（modelscope这样的应该也有）作为你学习的工具，记住一定要保管好，并且尽量避免让ai看到（可以创建一个.env文件）
然后对着官方的API使用文档（https://api-docs.deepseek.com/zh-cn/），告诉ai，你想要搭建一个ai对话式的项目，然后api重点关注这个：
```
 "messages": [
    {
      "content": "You are a helpful assistant",
      "role": "system"
    },
    {
      "content": "Hi",
      "role": "user"
    }
  ],
```
这代表了你向ai api 输入的内容。
然后他会返回这样一个同样是messages的字段：
```
  "choices": [
    {
      "finish_reason": "stop",
      "index": 0,
      "message": {
        "content": "Hello! How can I help you today?",
        "role": "assistant"
      }
    }
  ],
```
先一步搭建起来这次一轮对话还是比较简单的。

后面呢，是给返回的message内容加入到输入的数组里面，构成循环，你就会发现ai可以跟你多轮会话了。

第三步：让ai学会创建你电脑的文件。给输入的tools字段加上关于shell命令的使用简介（比方说cat命令创建文件，这比较明显），然后响应返回的后一步加一段代码可以检查ai是否调用工具，如果有执行命令。最后看看你电脑文件夹有没有成功新建了一个文件，如果有那么就成功了！
在这之后，你就可以正式开始关于agent实习：
https://github.com/shareAI-lab/learn-claude-code

## 计算机

### 前端

首先非常推荐大伙去看MDN这个网站：https://developer.mozilla.org/zh-CN/，可以说它教会了你怎么基本搭建出一个基本的网站。第一步就是从写一份html走起，写下
`<p>hello world!</p>`，然后在github新建一个index.html，登陆：（你的账号）.github.io，于是你得到了第一份属于你自己的网站～

然后在就是根据这个网站，逐渐加入css样式，js的编程语言，让这个网站能够动起来，色彩丰富起来。

然后是服务器的一些搭建知识，为了能够让网站显示动态的数据，我们需要另行一个网站提供服务，mdn也给了我们这个教程：
https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Extensions/Server-side

最后，你就可以使用ai工具，借助vue或者react框架搭建起一个你想要的现代化网站了！在这里的建议是，新手不建议直接去看vue，react的官方文档，然后记笔记式的学习，建议是跟随ai搭建网站的过程，你看每一步它是怎么实现的，比如vue的computed(),react的useeffect，关于每个细节你都需要向ai问明白，这样才是一个好的实践式学习方式，而且你记的也牢。

如果你完成了以上的搭建并且对于知识有所学习而不是只是看着ai开发不动脑，那么你也入了前端这个领域。
