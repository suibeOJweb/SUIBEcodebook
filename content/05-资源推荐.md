# 资源推荐

> 返回 [目录](/)

除了在学校的部分，有很多你们不知道的资源都汇总在这了

## 课程

### 计算机基础（优先级最高）

- **CSAPP（深入理解计算机系统）**：CMU 的招牌课（15-213），讲透程序在机器层面如何运行，跟着b站上一个叫九曲阑干的up去学。如果你研究其中一个领域入门了，看这门课正合适，看完你对"程序到底是什么"的理解会上一个台阶。
- **jyy 操作系统**：南京大学蒋炎岩老师的操作系统课，B 站有录播的。讲课风格极其硬核又有趣，全程 live coding，是中文世界最好的 OS 课，为数不多能比上国外的名校课程。另外jyy近期还有对ai的独立见解，我是相当推荐去看的。
- **计算机网络**：推荐中科大郑烇老师的计网课（B 站有）。
- **Missing Semester（MIT）**：学校不教但程序员每天都用的东西：Shell、Vim、Git、调试、命令行工具。

### 数学

- **3Blue1Brown**：用动画建立数学直觉。线性代数系列和微积分系列必看，神经网络系列是理解深度学习最好的入门材料。

## 网站 / 文档

- **MDN Web Docs**：前端/Web 技术的权威文档，学前端入门就住在这里。
- **JavaGuide**：Java 后端学习与面试的中文开源指南，覆盖 Java 基础、并发、JVM、框架、中间件，就业向必备。
- **小林 coding**：图解计算机网络、操作系统、MySQL、Redis，然后现在还有ai，rag的知识，面试八股里写得最好懂的一类，如果要面试的话可以看
- **roadmap.sh**：各个方向（前端/后端/DevOps/AI……）的学习路线图，不知道自己该学什么的时候先看它。
- **菜鸟教程 / 廖雪峰的官方网站**：快速查语法、入门某门语言时用，适合当字典而不是当教材，也就是说忘了看，而不是一个一个看。
- **LeetCode**：力扣刷一定题增长对程序语言，算法的见解还是有必要的，而且互联网笔试这块也要用到。当然你要打算法竞赛的话，还是去刷洛谷/codeforces吧。
- **GitHub**：本身就是最大的学习资源库。关注优质开源项目、读别人的代码，比看教程进步快，然后关注一下awesome系列，这基本上是github上的精品合集了，然后每周trend也帮助你找到一些行业趋势跟好玩的项目（题外话：也有可能找到一些神秘二次元头像贡献的项目，多半有个qq群放在README（逃））。我很建议你们把github设置快捷方式到手机里面，别小瞧这一小步，很多时候的了解都是从这里开始的。
- **Stack Overflow**：遇到问题先搜它（以及现在先问 AI），学会看英文答案。
- **DeepWiki**：了解github项目必备的网站，这个是由ai智能生成关于项目的wiki，你还能关于项目内部的技术问题向ai提问，比看源码理解快多了。
- **Datawhale系列** ：首先这是一个github的简中开源组织，专门出一系列关于ai教程的，很适合小白，伟大无需多言。

## 开源活动
如果想了解趋势，了解实际工程经验，这些都可以作为参考，多多参加，实力自然会变强，而且也能结识不少志同道合的朋友。
- **字节青训营/腾讯菁英班/腾讯犀牛鸟计划...** ：这些首先是大厂推出的面向高校学生的实战培训，质量的话是可以的，尤其是犀牛鸟跟青训营，可以为它们加上属于自己的代码，而且成功结项的话也能大大提高进入对应厂商的面试机会。
- **开源之夏/gsoc** ：这个也是能给海量高星项目提供贡献的机会，质量很高的，提升水平很快。
- **Vue Conf/Pycon等会议** ：不少专门的领域会邀请人来分享领域内有意思的技术点探索，收获会很多，不过要注意有些会议只是单纯的产品推销会，技术却并没有讲多少，这个注意一下。
- **hackson黑客松**：这个是你亲手参加的一类活动，要求在短时间内完成对应项目给人看。
