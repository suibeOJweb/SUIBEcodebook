## 为什么写这本 Codebook

一切都源自于笔者自主拓展探索的困难。

笔者是人工智能专业的第二届学生。由于学校刚开设计算机、AI 领域的专业，各方面的资源和经验都过于短缺。大一下学期，我跟两位大数据的学长组建了一支 ACM 队伍，网络赛成功入围，也在学校组织了一些院级活动，可惜在济南区域赛后打了铁。之后大家因为各自忙别的事情，队伍最终不告而终。（ACM 本身如何，那更是后话了。）

我也是一名兴趣使然的学生，但直到大三上学期才算真正对工程领域入了行。当时网上常见的内容，要么过于 boring，动不动就是高并发、微服务、容器、推理框架这些让初学者完全陌生的项目；要么就是菜鸟、尚硅谷这类培训班的资源课，做出来的项目对我们而言也缺乏意义。最后，我在看 Thoughts Memo 的文章时，偶然接触到如何搭建并上线一个基本的网站——虽然那只是一个 HTML 页面，还挂在 GitHub 域名上，没有涉及服务器本身的概念，但这依然是我自己创作的第一个作品，我也由此慢慢入了前端领域。

至于 Agent 领域，一切起源于我在一次技术群中的观察：我给一家 Agent 初创投了简历，老板给了我一次黑客松式的面试——几天内构建一个类似 Claude Code 的项目，相关博客可以看公司发的。虽然结果比较失败，GAIA 测试通过率很低，但我同样意识到，AI 原来也可以帮我创造出一些东西，于是开始系统学习 Agent 知识。

我花这么多笔墨说明这些经历，是为了印证一件事情：**AI / 计算机领域其实是一门很有意思的学科，不单单只是面向工作编程。你在创造的同时收获了知识和工程经验，这时候再去实习，不说信手拈来，但确实会省下很多预先准备的知识和精力。**

## AI 时代的另一个优势：门槛降低了

AI 时代的到来还带来了一个优势——了解技术的门槛降低了。你可以向 AI 提问，向 AI 咨询如何从零开始，主动出击，而不是对着一堆高难名词和面试经验发愁。

我相当提倡学弟学妹从 vibe coding 开始。不要只听"哦，你一定需要先听完操作系统、计算机网络、计算机体系结构、数据结构与算法……才能上手"这种说法。我承认这些传统课程很有必要——踩了很多坑之后你会发现它们确实需要好好听——但这并不意味着你就没有资格去上手一个项目。多用 token，多动脑，多借助 AI 拓展思路，这是相当重要的。

## 以兴趣驱动学习

所以，希望大伙秉持兴趣学习。随着 AI 时代的到来，未来越来越不确定，萝卜坑也没有以前那么多了——以兴趣驱动的长期收益，正在逐渐赶上功利学习的短期收益（不过也可能是一厢情愿，毕竟市场上劣币驱逐良币的也不少）。
